## 3. Пользовательский образ системы (дополненная версия)

### 3.1. Назначение системы
Система предназначена для **автоматизированного химического контроля водной среды обитания аквакультуры** в цикле «рыбоводная зона — зона водоочистки».

### 3.2. Ключевые характеристики (как видит пользователь)

| Характеристика | Описание |
|----------------|----------|
| **Объект контроля** | Водная среда в двух точках: **вход и выход зоны очистных сооружений** |
| **Измерение** | Данные поступают от прибора **АТОН-801** (8 каналов), установленного в лаборатории ВИШ МИФИ |
| **Перечень параметров** | **NH₄⁺, NO₃⁻, NO₂⁻, pH, удельная электропроводность, Na⁺, O₂, температура** |
| **Сбор данных** | Контроллеры прибора собирают, накапливают, усредняют и передают данные в ЦОД предприятия по локальной сети |
| **Хранение (ЦОД)** | Логи хранятся в удобном формате (БД, файлы) за длительный период (например, год) |
| **Визуализация** | На АРМ оператора отображаются графики динамики параметров |
| **Зоны отклонений** | **Зелёная (норма), жёлтая (значительные отклонения), красная (недопустимые отклонения)** |
| **Оповещение оператора** | При выходе из зелёной зоны и при переходе жёлтая → красная |
| **Оповещение ответственных лиц** | **Индивидуальные уведомления при красной зоне (согласованным способом)** |
| **Удалённый доступ** | Ответственные работники подключаются к ЦОД через Интернет по VPN с авторизацией |
| **Удалённый сервер** | Данные регулярно выгружаются на удалённый сервер для долгосрочного хранения (многие годы) |
| **Доступ аналитиков** | Аналитики-технологи имеют доступ к удалённому серверу через Интернет с отдельными правами |
| **Администрирование** | Управление доступом, резервное копирование, контроль VPN |

### 3.3. Ожидания пользователей от системы

- **Оператор:**  
  «Я должен видеть, в какой зоне находятся параметры, и получать чёткие сигналы при любом выходе за пределы нормы».

- **Ответственный работник (инженер/технолог):**  
  «Я хочу получать индивидуальные уведомления о критических отклонениях и иметь возможность удалённо подключиться к данным, чтобы быстро принять решение».

- **Аналитик-технолог:**  
  «Мне нужен доступ к многолетним данным с разных объектов для поиска закономерностей и научных выводов».

- **Администратор:**  
  «Я должен управлять пользователями, обеспечивать защиту каналов и сохранность данных на всех уровнях».
